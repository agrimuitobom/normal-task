# 教員業務フロー

## 年間スケジュール概要

| 時期 | 主な業務 |
|------|----------|
| 4月 | 新年度準備、クラス編成、年間計画作成、保護者説明会 |
| 5月 | 家庭訪問、健康診断、前期中間考査 |
| 6月 | 校外学習、進路指導（中3・高3）、前期中間考査返却・分析 |
| 7月 | 前期期末考査、通知表作成、保護者面談、終業式 |
| 8月 | 夏季休業、研修・研究、後期準備 |
| 9月 | 始業式、体育祭・文化祭準備 |
| 10月 | 後期中間考査、学校行事（体育祭・文化祭） |
| 11月 | 進路指導、後期中間考査返却・分析 |
| 12月 | 後期期末考査、通知表作成、保護者面談、終業式 |
| 1月 | 始業式、入試対応（中3・高3） |
| 2月 | 後期末考査、次年度準備 |
| 3月 | 学年末処理、卒業式、修了式、引き継ぎ |

---

## 月間業務フロー（標準例）

### 月初め
- [ ] 月間計画の確認・調整
- [ ] 提出物（提案文書等）の締め切り確認
- [ ] 翌月の行事・試験の準備着手

### 月中
- [ ] 授業計画書の提出（必要な場合）
- [ ] 各種報告書・記録の更新
- [ ] 生徒面談・相談対応のログ記録

### 月末
- [ ] 成績・評価の入力・提出
- [ ] 翌月の行事通知文の作成・配布
- [ ] 職員会議での報告事項まとめ

---

## 成績管理の流れ

```
1. テスト実施・採点
        ↓
2. CSVファイルに得点を入力
   （氏名,国語,数学,英語,理科,社会）
        ↓
3. スクリプトで集計
   python scripts/grade_summary.py grades.csv
        ↓
4. 結果を成績システムに転記
        ↓
5. 通知表・保護者面談資料に反映
```
